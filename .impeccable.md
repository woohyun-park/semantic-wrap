## Design Context

### Users

Frontend developers and designers working with responsive Korean and English headlines. They need to understand semantic-wrap quickly, verify that its line-break decisions improve real typography, and copy a production-ready integration into React or a framework-agnostic environment.

### Brand Personality

Precise, calm, and typographic. The interface should feel like a carefully calibrated typesetting instrument: technically credible without becoming clinical, and expressive without distracting from the text itself.

### Aesthetic Direction

A dark editorial interface derived directly from the existing `assets/semantic-wrap-lockup.webp` artwork. Preserve its sampled core palette—ink `#16181b`, paper `#fbfbfb`, electric blue `#538bf6`, and pale blue `#90bdf9`—along with fine dotted registration marks and soft organic boundary curves. The memorable visual is a simultaneous browser-versus-semantic comparison where a headline reflows into a more meaningful shape as its measure changes. Avoid generic developer-dashboard cards, decorative space effects, glassmorphism, and blue-purple gradient spectacle. Support responsive layouts, keyboard use, WCAG AA contrast, and reduced motion.

### Design Principles

1. Make the line-breaking result the hero; decoration must frame the typography, never compete with it.
2. Show the value before explaining the algorithm through live resizing and native-versus-semantic comparison.
3. Use asymmetry, editorial rhythm, and visible typographic measures instead of repetitive card grids.
4. Keep interaction immediate and legible across pointer, touch, keyboard, and reduced-motion contexts.
5. Present technical detail progressively: quick start first, diagnostics and strategy concepts later.
